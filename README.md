# FirstReactApplication

A full-stack weather application built with React + TypeScript and .NET 8.

## Features
- Real-time weather data from OpenWeatherMap API
- Weather predictions using AI
- Responsive React frontend with Vite
- RESTful ASP.NET Core backend

## Tech Stack
- **Frontend:** React 19, TypeScript, Vite
- **Backend:** .NET 8, ASP.NET Core
- **APIs:** OpenWeatherMap, Anthropic/Google Generative AI

## Prerequisites
- .NET 8 SDK
- Node.js 18+
- npm or yarn

## Setup

### Backend
1. Navigate to `FirstReactApplication.Server`
2. Create `appsettings.json` (copy from `appsettings.example.json`)
3. Add your API keys

### Frontend
1. Navigate to `firstreactapplication.client`
2. Run `npm install`

## Running Locally
- Open the solution in Visual Studio 2022
- Press F5 to run (starts both backend and frontend)
